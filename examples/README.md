# Examples

These files are synthetic authoring, contract, simulation, and adapter examples.
They demonstrate versioned capability, resource-binding, ROS 2 runtime, and
evidence shapes without defining a robot-side Flyto2 runtime.

Simulation and physical resources should expose the same semantic capabilities
and observation/evidence contracts. Their provenance differs; the Cloud
authority, verification, and recovery semantics do not.

Never treat an example endpoint, robot id, token-shaped value, map, or simulated
pose as production configuration.
